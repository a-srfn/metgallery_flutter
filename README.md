# MetGallery

A Flutter mobile application using The Metropolitan Museum of Art Collection API.

## Features

- Browse museum departments
- Browse artworks
- View artwork details
- Save artworks to offline library
- View saved artworks offline

## API

https://metmuseum.github.io/

## Technologies

- Flutter
- HTTP
- Hive CE

## Screens

1. Departments Screen
2. Artworks Screen
3. Artwork Details Screen
4. Offline Library Screen
